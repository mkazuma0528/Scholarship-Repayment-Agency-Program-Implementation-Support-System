Icon system selection / 2026

絵文字をやめて、
アイコンを標準装備にする。

HP・提案資料・管理画面で使うピクトグラムを、3つの候補ライブラリで実物比較しました。このページに並んでいる図形はすべて各ライブラリの実データ（SVG）で、スクリーンショットではありません。同じ意味のアイコンを横に並べているので、線の太さ・角の丸み・余白の取り方といった「性格の差」がそのまま見比べられます。

掲載数 約390種を実埋め込み 検証バージョン Phosphor 2.1.1 / Iconoir 7.12.1 / Hugeicons Free 4.3.2 作成 2026-09-13

01 — Overview

3つの候補、ひとことで言うと

同じ6つの概念（学位帽・銀行・提携・成長グラフ・保護・複数人）を各ライブラリで描いたもの。この6個だけでも、線の性格がかなり違うのが分かります。

Phosphor Icons

完全無料

有機的でやわらかい輪郭。1つのアイコンに6段階の太さがあるのが最大の武器で、見出しは Bold、本文横は Light、といった「太さで階層を作る」使い方ができます。Duotone（2色）は当社ゴールドとの相性が良好。

完全無料

幾何学的で線幅が一定、クセがなく上品。24pxグリッド・線幅1.5で完全統一されているため、管理画面のように大量のアイコンを等間隔で並べる画面で最も破綻しにくい。反面、語彙数は3つの中で最少。

無料 + 有料

角が丸くモダンな今どきSaaS風。語彙数が桁違いで、「該当するアイコンが無い」がほぼ起きません。無料版でも6,025種。10スタイル（塗り・2色・シャープ等）を揃えたいときだけ有料が必要になります。

03 — Cost

かかるお金は Hugeicons だけ

Phosphor と Iconoir は有料プランが存在しません（MITライセンスの完全な無償配布）。検討が必要なのは Hugeicons の Pro に上げるかどうかだけです。円換算は1ドル＝150円で計算した概算で、実際の請求額は決済時のレートによります。

Phosphor / Iconoir

¥0

MIT ライセンス・請求なし

  • 全アイコン・全スタイルが最初から利用可能
  • 商用利用・改変・再配布いずれも可
  • クレジット表記の義務なし
  • 人数・席数の制限なし

  • ダウンロード済みファイルは解約後も使い続けられる
  • プラグイン・CDN等のオンライン機能は毎年更新が必要

Hugeicons Pro Plus

$1,197

買い切り・1席 ≒ 約180,000円

  • 更新なし。オンライン機能も永続利用

07 — Implementation

導入のしかた

3つとも React / Vue で同じ感覚で使えます。資料やスライドに貼るだけなら、各サイトでアイコンを選んで SVG をコピーするだけで済みます。

Phosphor Icons

# React
npm i @phosphor-icons/react

// 太さは weight で指定
import { GraduationCap } from
  '@phosphor-icons/react';

<GraduationCap
  size={32}
  weight="duotone"
  color="#c9a84c" />

Iconoir

# React
npm i iconoir-react

// 線幅は strokeWidth で調整
import { GraduationCap } from
  'iconoir-react';

<GraduationCap
  width={32} height={32}
  strokeWidth={1.5}
  color="#c9a84c" />

Hugeicons

# React（無料版）
npm i @hugeicons/react \
  @hugeicons/core-free-icons

import { HugeiconsIcon } from '@hugeicons/react';
import { Mortarboard01Icon } from
  '@hugeicons/core-free-icons';

<HugeiconsIcon icon={Mortarboard01Icon}
  size={32} color="#c9a84c" />

08 — Recommendation

どう使い分けるか

結論としては、まず Phosphor を標準にして、語彙が足りないところだけ Hugeicons 無料版で埋めるのが現実的です。どちらもMITなので費用は発生しません。有料化の判断は「Figmaで全スタイルを使いたくなったら」で十分間に合います。

第一候補 — 標準として採用

Phosphor Icons

提案資料・LP・スライドのように「大きく見せる」用途に最も強い。6ウェイトで階層が作れ、Duotone はゴールドとの二色使いがそのままブランド表現になります。丸みのある輪郭は、金融寄りの硬い題材をやわらげる方向に効きます。無料・MIT。

併用 — 語彙の穴埋めに

Hugeicons（無料版）

6,025種という語彙量が武器。奨学金・人事・請求まわりのように概念が細かい領域で「ぴったりの絵が無い」という事態をほぼ潰せます。Phosphor と同じ角丸系なので、混ぜても浮きにくいのも利点。有料化は Figma 運用を本格化する段階で再検討すれば十分です。

条件付き — 管理画面なら

Iconoir

線幅と余白が徹底して均一なので、テーブルやサイドナビにアイコンを敷き詰める管理画面では最も整って見えます。一方で語彙が最少、塗りスタイルも288種のみ。Web管理画面専用として割り切るなら有力ですが、全社標準には語彙が足りません。

アイコンはすべて各ライブラリの配布パッケージ（npm）から実データを取得して埋め込んでいます。収録数はパッケージ内のファイルを実測した値、Hugeicons Pro の点数と料金は公開情報に基づく参考値です。料金・収録数は改定される可能性があるため、発注前に各公式サイトでご確認ください。
