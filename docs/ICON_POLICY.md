# アイコン方針を全プロジェクトに効かせる設定

このリポジトリでは `CLAUDE.md` に書いてあるので、ここで Claude Code を動かす限り自動で適用される。
**他のプロジェクトや、ローカルの Claude Code 全体にも効かせたい場合**は、
下のブロックを自分のマシンの `~/.claude/CLAUDE.md` に追記する（無ければ新規作成）。

```bash
mkdir -p ~/.claude && ${EDITOR:-nano} ~/.claude/CLAUDE.md
```

`~/.claude/CLAUDE.md` は全プロジェクト共通のメモリとして毎回読み込まれるため、リポジトリを問わず効く。
プロジェクト側に `CLAUDE.md` があれば、そちらの記述が優先される。

---

## コピーして貼るブロック

```markdown
## アイコン（絵文字は使わない）

成果物に絵文字を使わない。絵文字は OS ごとに字形と色が変わり、ブランドカラーに揃わないため。
- HP・LP・管理画面・提案資料・スライド: アイコンライブラリの SVG を使う
- Markdown ドキュメント・README: 装飾目的の絵文字を付けない
- コード・ログ出力・コミットメッセージ: 絵文字を入れず [OK] [NG] のような文字で書く
- 意味を持つチェック記号は、絵文字表現を持たない ✓ ✗ □ で代替する

- 第一候補: Phosphor Icons（MIT・無料・1,512種 × 6ウェイト / npm `@phosphor-icons/core`）
- Phosphor に該当する絵が無いときだけ Hugeicons 無料版
  （MIT・無料・6,025種 / npm `@hugeicons/core-free-icons`）で補う
- Iconoir は使わない（語彙不足）

実装ルール:
- インライン SVG で埋め込む。外部 CDN の webfont・スタイルシートは参照しない
  （Artifact の CSP でブロックされ、無言で表示が消える）
- 色は currentColor で親から継承させ、fill を直書きしない
- アクセントカラーは #c9a84c
- 同じアイコンを 3 回以上使うなら <symbol> スプライト化して <use> で参照する
- 装飾用途は aria-hidden="true"、アイコン単体のボタンには aria-label

太さで階層を付けるときは Phosphor のウェイトを使い分ける:
本文の横は light、セクション見出しは bold、表紙の主役は duotone。
```

## 効かせ方の使い分け

| やりたいこと | 置き場所 | 状態 |
|---|---|---|
| このリポジトリだけ | `CLAUDE.md` | 設定済み |
| 自分の全プロジェクト | `~/.claude/CLAUDE.md` に上のブロックを追記 | 各自のローカルで実施 |
| 会社全体に強制 | 組織の managed settings（PLACZ デザインルール） | 管理者対応 |

## 注意

- `~/.claude/CLAUDE.md` は**各自のローカルマシン**の設定なので、メンバーごとに追記が必要。
  チーム全体で揃えたいなら、各リポジトリの `CLAUDE.md` に置くか、管理者にデザインルールへの追記を依頼する。
- これは「Claude がそう書く」というルールであって、機械的な検査ではない。
  絵文字の混入をコミット前に止めたい場合は、別途 pre-commit フックでの検出が必要。
