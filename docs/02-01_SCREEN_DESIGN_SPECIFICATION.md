## 1. 画面設計概要

### 1.1 設計方針

#### デザインシステム
- **デザインフレームワーク**: Tailwind CSS
- **カラーパレット**: ビジネス向けの信頼感のある配色
- **タイポグラフィ**: Inter フォントファミリー
- **レスポンシブ**: モバイルファースト設計
- **アクセシビリティ**: WCAG 2.1 AA準拠

#### ユーザビリティ方針
- **直感的操作**: 3クリック以内で主要機能にアクセス
- **一貫性**: 全画面で統一されたUI/UX
- **フィードバック**: 操作に対する明確な反応
- **エラー防止**: 入力ミスを防ぐ設計

### 1.2 画面構成

```
サイト構成:
├── 認証系
│   ├── ログイン画面
│   ├── パスワードリセット画面
│   └── 初回パスワード設定画面
├── メイン系
│   ├── ダッシュボード
│   ├── 申請管理
│   ├── 支払管理
│   ├── ユーザー管理
│   └── システム設定
└── 共通系
    ├── ヘッダー
    ├── サイドナビゲーション
    ├── フッター
    └── モーダル・ダイアログ
```

| 項目 | 仕様 | バリデーション |
